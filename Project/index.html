About

What it does

You write down a study session and the page adds up your hours, counts your streak and shows a bar chart of the last 7 days.

How it is made

Plain HTML, CSS and JavaScript. No libraries. The layout uses CSS Grid for the sections and Flexbox for the smaller parts.

Where the data is

In localStorage in your browser. If you clear your browser data the sessions are gone, and they do not move to another computer.

Questions

Do I need an account?

No. Everything is saved in your own browser.

How is the streak counted?

How many days in a row you have logged something, counting back from today. If you skip a day it goes back to zero.

Can I change a session after saving it?

Not yet. You have to delete it and add it again. I would like to add editing later.

Does it work on a phone?

Yes. The layout changes to one column and the menu turns into a button at 900px.
