## How to run it

The site is plain HTML, CSS and JavaScript, so there is nothing to install.

The easiest way is to open the live link above.

To run it on your own computer:

1. Download or clone the repository
   ```
   git clone https://github.com/fizzytri/software-development-skills-frontend.git
   ```
2. Open the `Project` folder
3. Open `index.html` in a browser

If you use VS Code you can also right click `index.html` and choose
"Open with Live Server", which is what I used while making it.

One thing to know: the site saves your sessions with localStorage. Some browsers
block that when you open a file directly, so if nothing saves, use Live Server or
the live link instead.

## What the project has

- A page with a navigation bar that turns into a menu button on small screens
- Responsive CSS with media queries at 900px and 550px
- CSS Grid for the sections and Flexbox for the smaller parts
- Deployed with GitHub Pages
